# PySpark Training Session 🚀

Репозиторий для практики перевода SQL-запросов в PySpark DataFrame API. Идеально подходит для изучения синтаксиса PySpark через практические примеры.

## 📋 О проекте

Этот проект содержит набор готовых датафреймов PySpark и SQL-запросов разной сложности. Основная цель - практиковаться в переводе SQL-запросов в код PySpark, используя DataFrame API.

## 🛠 Технологии

- **PySpark** 3.0+
- **Python** 3.8+
- **Jupyter Notebook** (опционально)
